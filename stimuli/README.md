# Stimuli

This folder contains task materials, activity designs, visual stimulus files, and related presentation assets.

## Suggested structure

- `visual/` — image or display assets
- `instructions/` — written or scripted instructions
- `task_files/` — scripts or task definitions used in the study
- `activity_materials/` — physical or digital materials used during activities
